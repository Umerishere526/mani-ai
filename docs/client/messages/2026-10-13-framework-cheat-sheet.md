Framework Selection Guide for Muhammad
1. ABCDE: The user connects a specific event to a troubling belief and emotional reaction.
2. Thought Reframe: The user struggles with one persistent, painful thought that needs a more  balanced interpretation.
3. Behavioral Activation: The user has withdrawn, stopped participating in activities, or  lost motivation and needs help taking one manageable action.
4. Structured Problem-Solving: The user faces a practical problem and needs help determining what to do.
5. ACT Choice Point: The user knows what matters to them but is allowing difficult thoughts  or emotions to prevent meaningful action.
6. DBT STOP: The user is emotionally overwhelmed and needs to pause before reacting  impulsively.
Governing Principle: MANI must understand the underlying concern before selecting a  framework. The user's opening emotion alone does not determine which framework to use.
