# Journal

Claude's engineering notes for this project — technical insights, failed approaches, root causes, and muhammad's preferences.

Per the root CLAUDE.md, Claude searches this folder before starting complex tasks and writes here when something is worth remembering. These notes are machine-written; [[Home|the rest of the vault]] is yours.

## What belongs here

- A root cause that took real effort to find
- An approach that failed, and why — so it isn't retried
- A preference muhammad has stated
- Something noticed but out of scope, recorded instead of fixed

## What doesn't

- Anything already in `.claude/` or the code — no duplicating stack facts
- Task-local detail that stops mattering when the task ends
- Architecture decisions — those are ADRs in `Decisions/`

Use [[Templates/Journal|the journal template]]. Name files descriptively: `nativewind-v5-no-config.md`, not `notes-3.md`.
