# "I don't know" is the case Mani helps with, not one it routes around

Three forms of the same escape, each added after the one before it failed: skip a stage in silence (2026-10-09), a
Not sure button (removed the same week), and `let_go` after a second `not_yet` (2026-10-13). Each ended frameworks with
the person no clearer, so muhammad ruled on 2026-10-21 to remove the escape. Failure class 1 and 4 in
[[failure-classes-from-later-branches-2026-10-21]].

What replaced it:
- `walk.MOVES` has no `let_go`; `not_yet` never moves the walk, however often it is said. The only way out is the
  person's own `stop`, which retires the framework as declined.
- `mani_base.md`: when they don't know, think aloud with two or three loose possibilities from what they said, never
  the same twice, and leave room for something else; a fit is their answer in their words. The prompt got shorter.
- Endings: ABCDE's E is done only with a path; Thought Reframe's last working phase only with a believable, more
  hopeful thought. Both use the existing partial/gap mechanism (`path`, `believe`), no new code.

Watch for: people stuck on one stage for many turns (a design finding to bring back, never a cap to patch in), and
Mani deciding for them (a possibility counts as theirs only when they pick or restate it). With two frameworks live,
an empty `heading_toward` gives no offer (`repairs.offer_framework`): check it in the first manual run.

2026-10-22: the stored understanding is sent as `their_case` while a framework runs, so questions and possibilities are about
their problem, core issue and feeling. If stage questions still read generic, the next step is a per-stage `builds_on`, not more prompt text.

2026-10-22 (later): a long Supportive chat showed `feeling` replaced each turn, the problem replaced by a detail ten turns in,
new facts kept nowhere, and a stage asking what the check already held. The record now gathers feelings and `also`, freezes the
confirmed case once an offer opens, and five stages are judged against `their_case`. The chat-tester panel had been left on
`in_their_control` by the 2026-10-21 swap: when a key is renamed, grep the tester too.
